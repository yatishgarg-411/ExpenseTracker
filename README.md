# 💸 Expense Tracker App

This is a **full-stack Expense Tracker** application built with:

✨ **React** (frontend)  
⚡ **FastAPI** (backend API)  
🍃 **MongoDB** (database)

It allows users to:

✅ Register and log in securely  
✅ Track their **current balance**, **total income**, **total expenses**, and **last month’s spending**  
✅ Add new income or expense transactions  
✅ View all transactions with **search and category filters**  
✅ Visualize financial health in the **Analytics Dashboard**, including:
  📈 Income vs Expense chart (last 6 months)  
  🥧 Pie chart of expenses by category  

This app is designed to help **people of all ages, especially youngsters**, to easily keep track of their money and spending habits in a simple, clear way. 🧠💰

---

## ✨ Features

🔐 **User Authentication**
- 🔑 Sign up and log in
- 🛡️ JWT-based secure sessions

📊 **Dashboard**
- 🧮 Shows an overview of your finances:
  - 💰 Current Balance
  - 🟢 Total Income
  - 🔴 Total Expenses
  - 📆 Net Last Month

💵 **Transactions**
- ➕ Add transactions (income or expense)
- 📝 View transactions with:
  - 🔍 Search bar
  - 🗂️ Category filter (Food, Rent, Salary, etc.)
  - ✏️ Edit and 🗑️ delete options

📈 **Analytics**
- 📊 Income vs Expenses chart (last 6 months)
- 🥧 Pie chart of expenses by category

⏳ **Session Management**
- ⌛ JWT token expires after 1 hour
- 🚪 Automatic logout on expiry
